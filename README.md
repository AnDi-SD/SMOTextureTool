# SMO Texture Tool

Кроссплатформенная утилита для извлечения и замены текстур в `.smo`-моделях
PC-версии **Winx Club**.

Приложение:

- проверяет размеры секций, записанные в заголовке SMO;
- находит и показывает поддерживаемые текстурные блоки;
- экспортирует отдельные текстуры или весь набор в PNG;
- принимает PNG, BMP и JPEG для замены;
- пересобирает файл и обновляет его общий размер и размер секции данных;
- повторно разбирает результат перед сохранением.

## Разработка в VS Code

Требуется .NET 8 SDK или новее.

```powershell
dotnet restore SMOTextureTool.slnx
dotnet build SMOTextureTool.slnx
dotnet run --project SMOTextureTool/SMOTextureTool.csproj
```

В каталоге `.vscode` также находятся готовые задачи `build`, `run` и
`test SMO format`.

## Структура

- `SMOTextureTool.Core` — чтение, проверка, декодирование и пересборка SMO;
- `SMOTextureTool` — интерфейс на Avalonia;
- `SMOTextureTool.FormatTests` — проверки на исходных файлах из `Samples`;
- `Samples` — набор реальных моделей для исследования формата.

Проверка образцов:

```powershell
dotnet run --project SMOTextureTool.FormatTests/SMOTextureTool.FormatTests.csproj
```

Тест проверяет количество текстур, извлечение и точный побайтовый round-trip.
Если экспортированная текстура не изменялась, после её обратной упаковки должен
получиться файл, полностью совпадающий с оригиналом.

## Поддерживаемые варианты

- `0x32E3` и `0x43E3`, раскладка каналов ABGR;
- `0x29E3`, раскладка каналов BGRA.

Для всех вариантов безопасна замена изображения с сохранением исходных размеров.
Для `0x32E3`, `0x43E3` и `0x29E3` разрешены HD-размеры до `16384×16384`;
обе стороны должны быть степенями двойки. Вложенные размеры текстурных блоков
записаны как `UInt32`, поэтому поддерживается и квадрат `2048×2048`.
Интерфейс по умолчанию работает в безопасном режиме с пределом `4096×4096`;
экспериментальный предел включается отдельным переключателем.

В интерфейсе доступны режимы предпросмотра RGBA, RGB без прозрачности,
альфа-канала, RGBA на шахматном фоне и `Окраска модели`. Последний режим для
монохромной текстуры с `D3DTOP_MODULATE` восстанавливает явную связь
`spModel → spMaterialData/spMeshData`, использует индексный буфер только этого
меша, растеризует diffuse-цвета его вершин по UV и показывает результат
умножения. Все режимы меняют только отображение и не затрагивают экспортируемые
или упаковываемые данные.

Для каждой текстуры также выводятся подтверждённые сведения о хранении и
каналах: ABGR/BGRA, диапазоны R/G/B/A, количество значений альфа-канала и факт
полного совпадения RGB. Предполагаемая роль материала не назначается по виду
пикселей.
Замена `1024×1024` в `Alfea01.smo` успешно проверена в оригинальной игре.

У `0x29E3` служебные поля начинаются с непривычных невыровненных смещений;
репакер обновляет каждое полное 32-битное значение.
